# Homelab Infrastructure

## Overview

This repository documents my self-hosted homelab infrastructure and the systems I have built and maintained on it.

The current environment is **Version 1.0**, built and administered primarily through SSH and the Linux terminal on an Ubuntu virtual machine running on Proxmox.

The project combines virutualization, Linux system administration, networking, server management, monitoring, and web development.

## Version 1.0

### Infrastructure

- Dell OptiPlex 3070 Micro
- Proxmox VE
- Ubuntu Linux virtual machine
- Virtualized services and applications

### Monitoring Dashboard

Version 1.0 includes a custom web-based monitoring dashboard built with:

- HTML
- CSS
- JavaScript
- Python
- Proxmox API

The dashboard provides visibility into the homelab's infrastructure and resource usage.

### Minecraft Server

The homelab also hosts a modded Minecraft server running:

- Minecraft 1.21.1
- Fabric
- Fabric API
- Multiple gameplay and world-generation mods
- RCON for server administration
- systemd for service management
